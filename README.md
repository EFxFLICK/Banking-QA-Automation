# Banking QA Automation Framework

Production-quality QA automation framework for testing a banking application across UI, API, and database layers.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- Playwright Test Runner
- REST API Testing
- Database Testing
- HSQLDB
- Allure
- GitHub Actions
- Docker

## Project Status

🚧 Under active development

## Current Phase

Phase 1 — Project Bootstrap

## Planned Coverage

- Authentication
- Accounts
- Transactions
- Fund Transfers
- Bill Payments
- Loan Requests
- API Testing
- Database Validation
- UI/API/Database Integration
- Negative Testing
- CI/CD

## Architecture

UI + API + Database validation will be implemented using a scalable Playwright and TypeScript architecture.

## Disclaimer

This project is built for QA automation learning and portfolio demonstration using a publicly available banking demo application. No real financial accounts, credentials, or transactions are used.
